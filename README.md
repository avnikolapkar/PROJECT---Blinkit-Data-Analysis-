# PROJECT---Blinkit-Data-Analysis-
This project is an end-to-end data analysis of Blinkit's sales and customer data. It uses SQL, Python, Excel, and Power BI to uncover key business insights on sales performance, customer behavior, and operational efficiency.
The goal is to provide actionable recommendations through an interactive dashboard.

# Key Tools 
SQL: Data cleaning and transformation.

Python: Exploratory Data Analysis (EDA) and initial insights.

Excel: Basic data manipulation and KPI calculation.

Power BI: Interactive dashboard creation and visualization.

# Project Goals
Identify top-performing product categories and outlets.

Analyze the impact of customer ratings and product types on sales.

Provide data-driven insights to improve business strategy.
